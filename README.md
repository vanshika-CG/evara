# Evara — AI-Powered Women’s Health Companion

Evara is an AI-powered women’s health platform focused on personalized wellness, hormonal health, cycle tracking, and lifestyle guidance.

Built using:
- React Native
- MERN Stack
- Python FastAPI
- Machine Learning (PCOS Risk Prediction)

---

# Vision

Women often rely on generic diet and wellness advice without understanding how health changes with:

- Hormonal cycles
- BMI
- Lifestyle habits
- Daily mood & energy
- Menopause stages

Evara aims to become a living, empathetic health companion that adapts to each user in real-time.
